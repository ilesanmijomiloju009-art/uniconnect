# UniConnect — Development of a Centralised Student Information System for Multi-Campus Institution

UniConnect is a web-based student information system prototype developed as a final-year Computer Science project. The system is designed to centralise student information and services across a multi-campus institution through a single, accessible platform.

## Project Overview

The project addresses the challenge of accessing student services and campus-related information across multiple campuses by bringing key student-facing and administrative functions into one system.

## Key Features

- Student authentication and account management
- Student dashboard
- Student activity selection and management
- Resource access and booking
- Notifications and announcements
- Campus information and interactive campus map
- Discussion facilities
- Timetable and student information
- Student activity history and personal analytics
- Administrative management
- Staff dashboard
- Student identification features
- Accessibility support
- Search and navigation features

## Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Node.js (development/runtime environment)
- Git/GitHub (version control)

## Getting Started

```bash
git clone https://github.com/YOUR-USERNAME/uniconnect.git
cd uniconnect
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Project Context

This application was developed as a final-year Computer Science project titled **“Development of a Centralised Student Information System for Multi-Campus Institution.”**

The prototype focuses on demonstrating how a centralised web platform can improve access to student services and information across multiple campuses.
